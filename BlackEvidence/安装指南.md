# BlackEvidence 安装指南

> 适用：正式服 / 经典时光服（现在可测）、无限服（开服后）。
> 全程不需要改客户端、不需要注册表、不需要第三方库（录像助手除外，可选）。

---

## 0. 先确认文件夹结构（最常见的装错原因）

`AddOns` 下面必须**直接**是 `BlackEvidence` 文件夹，里面**直接**是 `.toc` 和 `.lua`：

```
Interface\AddOns\BlackEvidence\
├─ BlackEvidence.toc
├─ BlackEvidence_Mainline.toc
├─ BlackEvidence_Vanilla.toc
├─ ...（其它版本 TOC）
├─ Core.lua
├─ Profile.lua
└─ ...
```

**错误示例**（多套了一层，游戏里看不到插件）：

```
AddOns\BlackEvidence\BlackEvidence\BlackEvidence.toc   ← 错
AddOns\BlackEvidence.zip                               ← 错（没解压）
```

判断方法：`AddOns\BlackEvidence\BlackEvidence.toc` 这个文件必须存在。

---

## 1. 找到魔兽安装目录

任选一种：

1. 战网客户端 → 选中游戏 → 齿轮图标 → **在资源管理器中显示**；
2. 默认路径：
   - `C:\Program Files (x86)\World of Warcraft\`
   - 或 `D:\Games\World of Warcraft\`
3. 已经装过插件的，直接找 `Interface\AddOns`。

游戏目录下会看到这些"版本文件夹"：

| 版本文件夹 | 对应客户端 |
|---|---|
| `_retail_` | 正式服 |
| `_classic_era_` | 经典旧世（时光服 1.15.x） |
| `_classic_` | TBC / Wrath / Cata / Mists 共用的经典客户端 |
| `_classic_beta_` | 无限服（Forever，开服后） |

---

## 2. 复制插件

1. **先退出游戏**（不是退回角色选择，是彻底关掉）。
2. 把整个 `BlackEvidence` 文件夹复制到对应版本的 `Interface\AddOns\`。

| 客户端 | 目标路径 |
|---|---|
| 正式服 | `...\_retail_\Interface\AddOns\BlackEvidence\` |
| 经典旧世 | `...\_classic_era_\Interface\AddOns\BlackEvidence\` |
| TBC / Wrath / Cata / Mists | `...\_classic_\Interface\AddOns\BlackEvidence\` |
| 无限服 | `...\_classic_beta_\Interface\AddOns\BlackEvidence\` |

注意：

- **只复制 `BlackEvidence` 文件夹本身**，不要复制外层的 `wow-addon` 或 `docs`。
- 路径里有中文没问题；但**不要放在 OneDrive / 坚果云等同步目录**里，可能被文件锁影响。
- 两个客户端都测的话，两边各放一份（互不影响）。

---

## 3. 启用插件

1. 启动游戏，停在**角色选择界面**（先别进游戏）。
2. 左下角点 **插件** 按钮。
3. 列表里找到 **BlackEvidence**，勾选。
4. 如果显示"已过期 / Out of Date"：
   - 勾选左下角 **加载过期插件**，可以直接用；
   - 或者按第 4 节改 Interface 号。

进游戏后角色脚下会有一条欢迎日志（如果聊天框能看到）。

---

## 4. 处理"已过期"（可选，但建议改对）

在游戏里执行：

```
/dump select(4, GetBuildInfo())
```

会打印一个数字（例如 `120000` / `11507` / `16001`）。把这个数字填到**当前客户端对应的 TOC** 第一行：

| 客户端 | 改哪个文件 |
|---|---|
| 正式服 | `BlackEvidence_Mainline.toc` |
| 经典旧世 | `BlackEvidence_Vanilla.toc` |
| TBC | `BlackEvidence_TBC.toc` |
| Wrath | `BlackEvidence_Wrath.toc` |
| Cata | `BlackEvidence_Cata.toc` |
| Mists | `BlackEvidence_Mists.toc` |
| 无限服 | `BlackEvidence_Camelot.toc` |

改完 `/reload` 或重启游戏。

> 不改也能用，只是插件列表里一直显示"已过期"。

---

## 5. 首次自检（第一次装完必做）

进游戏后依次执行，把输出留着：

```
/be status
/be test
/be menu
```

正常应该看到：

- `客户端：[正式服] Interface 120000 | menu=modern | name=realm | sendChat=nameless ...`
  - 时光服应为 `menu=legacy`
  - 无限服应为 `menu=modern | name=surname`
- API 列表里 `Screenshot`、`SendChatMessage`、`GroupRoster` 相关应为 `OK`；
  `C_LootHistory` 在经典旧世是 `MISS`（正常，那版没有）。
- `/be test` 末尾会打印 `通过 N，失败 M`。
- `/be menu` 会显示 `modernMenu / 注入数量 / 展开次数 / 点击次数`。

如果 `/be` 提示"未知命令"，说明插件没加载成功，回到第 0、3 节检查。

---

## 6. 基础功能验证（5 分钟）

1. 右键一个队友或目标头像 → 菜单里应有 **加入黑名单**。
2. 点击 → 弹出备注框 → 写多行中文 → **保存**。
3. 屏幕上应出现一条本地提示；`/be evidence` 应多一条记录。
4. 打开 `...\Screenshots\`，应多一张 `WoWScrnShot_*.jpg`（或 png）。
5. `/reload` → `/be` → 黑名单还在。
6. 完全退出游戏 → 重登 → 还在（这一步验证 SavedVariables）。

管理页：`/be` 打开，三个 Tab：

- **黑名单**：搜索、新增、编辑、删除（会二次确认）
- **快照**：证据列表 + 全文复制
- **设置**：预警开关、是否发频道、冷却、录制范围、日志级别

## 7. 录像助手（可选）

不做这一步，插件也能用：截图、时间线、证据包都照常，只是没有视频。

### 7.1 依赖

| 依赖 | 要求 | 检查命令 |
|---|---|---|
| Python | 3.8+，安装时勾选 **Add Python to PATH** | `python --version` |
| ffmpeg | 任意较新版本，`ffmpeg -version` 能输出版本即可 | `ffmpeg -version` |

ffmpeg 获取方式（任选）：

- 下载 Windows 构建，解压后把 `bin` 目录加到系统 PATH；
- 或者不解压到 PATH，直接在 `recorder\config.ini` 里写全路径：
  ```ini
  [paths]
  ffmpeg = D:\tools\ffmpeg\bin\ffmpeg.exe
  ```
  （`ffprobe` 放在同一目录即可，程序会自动找。）

### 7.2 配置

打开 `BlackEvidence\recorder\config.ini`，**只需要填这一项**：

```ini
[paths]
wow_root = D:\Games\World of Warcraft
```

`wow_root` 两种写法都行：

- 安装根目录：`D:\Games\World of Warcraft`（程序自己找 `_retail_` / `_classic_era_` / `_classic_beta_`）
- 或直接指向某个版本目录：`D:\Games\World of Warcraft\_classic_era_`

默认参数（一般不用改）：

```ini
[recording]
video_seconds = 150     ; 保留最近 150 秒
segment_time  = 20      ; 20 秒一段
fps           = 15
crf           = 28

[evidence]
chat_seconds  = 180     ; 聊天回看 3 分钟
```

### 7.3 启动

1. 双击 `recorder\启动录像助手.bat`；
2. 窗口**保持开着**（可以最小化，不要关）；
3. 退出按 `Ctrl+C`。

启动后检查 `recorder\recorder.log`：

- 有 `选中目录：...\_retail_`（或对应版本）说明找对了；
- 提示 `未找到 ffmpeg` 说明第 7.1 步没配好；
- 提示 `另一个实例正在运行` 说明已经开了一个窗口（一个目录只能开一个）。

### 7.4 自检

```bat
cd /d "插件目录\BlackEvidence\recorder"
python blackevidence_recorder.py --selftest
```

会逐项检查：魔兽目录、Screenshots、Logs、WTF、ffmpeg、ffprobe、输出目录可写。
**只要有一项"失败：魔兽目录"，就是 `wow_root` 没填对。**

### 7.5 验证一次完整归档

1. 录像助手开着；
2. 游戏里随便找个玩家 → 加入黑名单 → 保存；
3. 等 10 秒左右，打开 `recorder\evidence\`，应出现一个目录：
   ```
   20261026-213045_WoWScrnShot_102626_213045\
   ├─ capture.jpg            触发现场截图
   ├─ replay.mp4             最近 150 秒
   ├─ chatlog_tail.txt       聊天原文
   ├─ loot_and_rolls.txt     筛出的掉落/ROLL 行
   ├─ note.txt               你写的备注（/reload 后补齐）
   └─ meta.json              元数据（时长/分段数/是否成功）
   ```
4. `index.jsonl` 里会多一行索引。

### 7.6 多客户端

一个录像助手只盯一个版本。要同时盯正式服和时光服：

- 复制整个 `recorder` 文件夹成两份；
- 两份 `config.ini` 分别填不同的 `wow_root`；
- 开两个窗口。

### 7.7 关于 OBS

录像助手已经替代了 OBS 回放缓存，**不需要装 OBS**。

如果你仍想用 OBS 兜底：当前版本**没有**实现屏幕上的 `BE_TRIGGER` 大字层（录像助手靠监听 `Screenshots` 新文件触发，不需要它）。需要的话可以后续补。

## 8. 数据位置与备份

插件数据在：

```
WTF\Account\<你的账号>\SavedVariables\BlackEvidence.lua
```

- 这一个文件里同时存着：黑名单、配置、日志、证据。
- **换电脑 / 重装游戏前，复制这个文件**即可带走全部黑名单。
- 也可以在游戏里 `/be export` 导出文本，换服后用 `/be import` 粘回去（支持跨版本合并）。

录像和聊天证据在：

```
BlackEvidence\recorder\evidence\
```

`_segments` 是临时分段，可以随时删；`evidence` 下的目录是归档，别乱删。

---

## 9. 升级 / 卸载

**升级**：

1. 退出游戏；
2. 用新版本整个覆盖 `AddOns\BlackEvidence\`（`SavedVariables` 不受影响）；
3. 进游戏 `/reload`。

**卸载**：

1. 删除 `AddOns\BlackEvidence\`；
2. 想彻底清干净，再删 `WTF\Account\<账号>\SavedVariables\BlackEvidence.lua`；
3. 录像助手目录单独删。

## 10. 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 插件列表里没有 BlackEvidence | 文件夹多套了一层；或 `.toc` 与文件夹不同名；或没解压 |
| 显示"已过期" | Interface 号不匹配，按第 4 节改；或勾"加载过期插件" |
| `/be` 提示未知命令 | 插件没加载，`/dump IsAddOnLoaded("BlackEvidence")` 看是否为 true |
| 右键没有"加入黑名单" | `/be menu` 看 `mode`；modern 路径没生效就发 `/be diag` |
| 管理页打不开或白框 | 客户端 UI 模板差异，发 `/be diag` |
| 加了黑名单，重登没了 | SavedVariables 未落盘；先 `/reload` 再退出；仍不行发 `/be diag` |
| 截图没生成 | 游戏里 `/be screenshot` 单独试；检查 `Screenshots` 目录权限 |
| 进队没预警 | 确认 `warnOnPartyJoin=true`；`/be scan` 手动扫；同队只报一次 |
| 队伍频道没消息 | 默认**不发**频道，只在本地提示；设置里打开"发到队伍频道" |
| 录像助手一启动就退出 | 看 `recorder.log`：多半是 `wow_root` 填错或已有实例在跑 |
| `replay.mp4` 只有几秒 | 刚启动还没积累到 150 秒；或 ffmpeg 分段被中断，看 `meta.json` 的 `video_ok` |
| 提示找不到 ffmpeg | PATH 没配，或 `config.ini` 的 `ffmpeg=` 路径写错 |
| 录像文件特别大 | 调高 `crf`（28→30）或降低 `fps`；也可以 `region` 只录游戏区域 |

---

## 11. 反馈问题时请提供

1. `/be status` 的完整输出；
2. `/be diag` 的完整输出；
3. 如果是录像问题：`recorder\recorder.log` + 出错那次的 `meta.json`；
4. 客户端版本：`/dump select(4, GetBuildInfo())`。

有这四样，基本不用你再描述现象。
