# Changelog

## 1.10.6

- 副本内部地图改由 DungeonQuestAtlas 的自定义副本地图覆盖层显示。
- 点击副本 BOSS 时先打开副本入口所在区域，再调用 DQA `ShowDungeonOnWorldMap` 显示副本平面图和 BOSS 位置。
- 客户端没有副本 `C_Map` ID 时，不再只停在入口，而是显示 DQA 的副本地图。
- `DungeonEntrance.lua` 现在包含 DQA 副本 key，便于调用覆盖层。

## 1.10.5

- 根据 `/hb mapdiag` 确认：这个 Forever 客户端只暴露区域地图，不暴露副本内部地图。166、291、317 等副本 ID 全部为 `nil`。
- 新增 `DungeonEntrance.lua`：副本地图 ID → 副本入口所在区域地图 + 入口坐标。
- 点击副本 BOSS/NPC 时，如果客户端没有副本地图，就打开副本入口所在区域地图，并标出入口。
  - 死亡矿井 → 西部荒野
  - 哀嚎洞穴 → 贫瘠之地
  - 影牙城堡 → 银松森林
  - 斯坦索姆 → 东瘟疫之地
  - 黑石深渊 → 灼热峡谷
  - 等等
- 聊天框提示“（副本入口）”，不再尝试打开不存在的副本内部地图。
- 普通区域地图恢复直接打开。

## 1.10.4

- 打开地图逻辑恢复为 DungeonQuestAtlas 同款：`C_Map.OpenWorldMap` + `WorldMapFrame:SetMapID`。
- 移除了额外的 `C_Map.OpenMap` 二次调用和 `GetMapID` 比较，避免真实地图被覆盖或打不开。
- 不再修改世界地图窗口的 FrameStrata，只让插件窗口保持 MEDIUM。
- 纳克萨玛斯入口兜底保留，但不会影响普通地图。

## 1.10.3

- 补全配方掉落 NPC 的中文名：斯尼德、曲奇、重拳先生、绿皮船长、基尔尼格、矿工约翰森、克雷什、考布莱恩、安娜科德拉、暗影军马、变异精灵龙等。
- 修复这些 NPC 点击后不打开地图：暗影军马 → 影牙城堡，变异精灵龙 → 哀嚎洞穴，洛丹伦队长 → 提瑞斯法林地。
- 不再用 DQA 的英文 BOSS 名覆盖中文名。
- 非数字的自定义地图键不再传给世界地图 API。

## 1.10.2

- 新增 `RecipeDrop.lua`：补录新锻造图纸的副本掉落来源。
- 保护者/助祭/十字军/守卫/老兵 链甲衬衫图纸（251340–251344）现在会显示掉落 NPC、区域和坐标。

- 配方掉落列表中的 NPC 可点击 `[标出]` 打开地图。
