# Changelog

## 1.9.8

- 当前 Forever 版本没有开放纳克萨玛斯：纳克萨玛斯来源现在标记为“当前版本未开放”。
- 默认勾选“隐藏未开放”，纳克萨玛斯专属装备不再出现在默认列表中。
- 取消勾选“隐藏未开放”后仍可查看这些装备，但来源会显示“未开放”，且不再尝试打开不存在的地图。
- 默认防骑向清单从 312 件变为当前版本可获取的 303 件（9 件纳克萨玛斯专属装备默认隐藏）。

## 1.9.7

- 纳克萨玛斯：先尝试 166、533、1557、162–167 和客户端地图名扫描。
- 如果客户端确实没有可用的纳克萨玛斯世界地图，自动改为打开 **东瘟疫之地（1423）**，并在地图上标出纳克萨玛斯入口（34.3, 19.5）。
- 聊天框会明确提示“客户端没有纳克萨玛斯世界地图，已打开东瘟疫之地的副本入口”。
- 新增 `/hb mapdiag`：打印客户端纳克萨玛斯候选地图 ID 和当前世界地图 ID。

## 1.9.6

- 纳克萨玛斯改为优先使用 DungeonPilot/QuestieDB 的 UiMapID **166**（之前误改成实例 ID 533）。
- 地图打开失败时自动尝试纳克萨玛斯候选 ID：166、533、1557、162–167。
- 新增客户端地图名称扫描：按“纳克萨玛斯 / Naxxramas”查找客户端实际存在的 UiMapID，再打开。
- 打开失败不会再停留或误报，会尝试下一个候选地图。

## 1.9.5

- 全量核对 56 个装备来源区域与副本地图。
- 修复安其拉神庙（AQ40）没有地图 ID：现在打开安其拉神庙地图 320。
- 修复“沉没的神庙”中文别名没有映射：现在打开 220（阿塔哈卡神庙）。
- 保留 `纳克萨玛斯 = 533` 修复。
- 标准副本、团本地图 ID 再次与 DungeonQuestAtlas 楼层地图交叉核对。

## 1.9.4

- 修复纳克萨玛斯地图：Forever 客户端的纳克萨玛斯地图 ID 是 **533**，不是 166。
- 中文“纳克萨玛斯”、英文 `Naxxramas`、AreaID 3456/16394 全部改为 533。
- 大十字军的腰带等纳克萨玛斯掉落，点击后打开纳克萨玛斯副本地图，而不是玩家当前位置。

## 1.9.3

- 修复副本地图：不再用 `C_Map.GetMapInfo` 拦截副本 ID，死亡矿井 291、哀嚎洞穴 279、影牙城堡 310、斯坦索姆 317 等都能直接打开。
- 修复中文副本名映射：`死亡矿井/黑暗深渊/影牙城堡/斯坦索姆` 现在指向副本 UiMapID，而不是所在大地图。
- 副本小怪没有精确坐标时，点击掉落 NPC 会打开副本地图（不再提示“没有位置信息”）。
- 副本 BOSS 仍用 DungeonQuestAtlas 的楼层坐标显示精确地图钉。
- 掉落条目分为“BOSS 精确坐标”和“副本/区域地图”两种，都会打开地图。

## 1.9.2

- 修复打开地图：改用 `C_Map.OpenWorldMap` + `WorldMapFrame:SetMapID`，不再错误打开玩家当前位置。
- 不再用 `C_Map.GetMapInfo` 拒绝副本地图（如斯坦索姆 317）。
- 修复地图打开后插件卡在 UI 下层：只抬高世界地图，不再把插件窗口压到 BACKGROUND。
- 世界地图钉改为 TOOLTIP 层，保证在地图上方可见。
- 掉落来源改为可点击列表：NPC 名字 + `[标出]` + 区域/坐标，点击直接打开对应地图并标点。
- 出售来源也支持 `[标出]`。
- 列表增加隔行底色，来源列更清晰。

## 1.9.1

- 列表新增“需要等级 / 物品等级”两列，来源改为单列彩色标签（多来源显示 `+N`）。
- 多选筛选改用标准勾选框，不再使用 `[x]` 文本。
- 删除“插入链接”按钮；Shift+左键仍可直接插入物品链接。
- 详情来源改成规范分段：任务装备显示“任务 / 接取 / 交付 / 任务链”，制造装备显示“制造 / 配方 / 图纸商人”。
- 任务链压缩为编号列表，只保留状态、序号和任务名，点击任务名查看完整详情。
- 世界地图增加插件自己的地图钉，不依赖 TomTom 也能看到 NPC/任务品位置。
- 继续清理英文：区域名、英文物品副标题、掉落通用名全部中文化。
