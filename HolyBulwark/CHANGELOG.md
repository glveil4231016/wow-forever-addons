# Changelog

## 1.7.0

- 更名 **圣光壁垒 / HolyBulwark**。
- 任务中文名：410 个任务（含整条任务链）。
- 任务链展示：每一步的中文名、接取 NPC、区域，标记当前步骤。
- 物品触发任务：显示起始物品与掉落怪物列表。
- 地图标记支持多位置菜单：任务链 NPC、掉落怪物、商人、首领。
- 掉落 BOSS 中文名：本地 `NpcZh.lua` 478 个 NPC。
- 没有物品等级时显示任务等级。
- 修复来源字显示为 “...” 与下拉框截断。
- 修复首次点击小地图图标不显示窗口。
- 小地图图标贴边、外圈对齐。
