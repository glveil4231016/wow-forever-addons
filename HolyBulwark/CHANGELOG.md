# Changelog

## 1.9.0

- 世界地图打开时自动把插件窗口降到地图下方，地图始终在最上层。
- 全中文显示：图纸商人区域名改为中文；英文 NPC/物品/任务名不再直接显示。
- 任务链完整度：接入 Completao 的 556 个任务数据，补全前置、接取/交付地点、任务品位置与掉落怪物。
- 任务链每一步显示 `[已完成] / [当前] / [未完成]`，按角色任务完成记录判断当前位置。
- 任务弹窗新增“任务描述 / 目标”、任务品、击杀目标、任务对象、任务品位置与掉落 NPC。
- 任务链里的任务名、接取/交付 NPC、任务品位置、任务对象、掉落 NPC 全部可点击并打开地图标点。
- 图纸商人行新增“标出”快捷链接。
- 修复任务链顺序：优先使用 Completao 的前置关系，避免出现奖励任务排在任务品之前。

## 1.8.0

- 配方图纸商人：新增 `RecipeVendor.lua`，记录 Wow Forever 图纸贩卖 NPC、区域与坐标。
- 制造装备“地图标记”现在可列出图纸商人；没有位置时给出明确提示，不再弹出空菜单。
- 经典配方自动回退到 QuestieDB 的商人数据（运行时读取）。
- 任务链：任务名与 NPC 名可点击；任务弹窗显示目标、接取/交付 NPC、任务品掉落与所需物品。
- 任务链标记由“当前”改为“本物品任务”，避免未接任务时误标。
- 多选筛选：部位、护甲、来源、品质均可多选；选中标记改为 `[x]`。
- 等级范围新增“查询”按钮，只有点击或回车才应用。
- Shift+左键插入可点击物品链接（自动打开聊天框）；Ctrl+左键打开试穿。
- 修复下拉菜单选中标记显示为方块的问题。

## 1.7.0

- 更名 **圣光壁垒 / HolyBulwark**。
- 任务中文名：410 个任务（含整条任务链）。
- 任务链展示：每一步的中文名、接取 NPC、区域，标记当前步骤。
- 物品触发任务：显示起始物品与掉落怪物列表。
- 地图标记支持多位置菜单：任务链 NPC、掉落怪物、商人、首领。
- 掉落 BOSS 中文名：本地 `NpcZh.lua` 478 个 NPC。
- 没有物品等级时显示任务等级。
- 修复来源字显示为 “...” 与下拉框截断。
- 修复首次点击小地图图标不显示窗口。
- 小地图图标贴边、外圈对齐。
